# Портфолио: лендинги

Демо-лендинги для портфолио. Все компании и люди вымышлены.

| Проект | Что показывает |
|---|---|
| [Репетитор английского](tutor/) | тарифы, отзывы, FAQ, форма записи с подстановкой тарифа |
| [Кофейня с обжаркой](coffee/) | тёмная тема, SVG-анимация, меню с вкладками |
| [Сервис ремонта техники](repair/) | калькулятор стоимости, маска телефона |

Стек: HTML, CSS, JavaScript без фреймворков. Адаптивная вёрстка под телефон.
Формы демонстрационные и никуда не отправляют данные.
